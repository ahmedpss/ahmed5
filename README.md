# دفترة — Daftara

دفتر ديون بسيط لأصحاب المحلات، يعمل بدون إنترنت. واجهة الويب (في مجلد `public/`) مغلّفة بـ Capacitor لبناء تطبيق أندرويد.

## بناء APK تجريبي (Debug) عبر GitHub Actions

1. ارفع محتويات هذا المجلد إلى جذر المستودع (ليس ملف ZIP نفسه).
2. افتح تبويب **Actions** ← **Build Daftara APK** ← **Run workflow**.
3. بعد انتهاء البناء افتح التشغيل ونزّل الـ Artifact باسم `daftara-debug-apk`.
4. فك الضغط لتحصل على `app-debug.apk`.

يُبنى المشروع أيضًا تلقائيًا عند أي push على الفرع `main`.

## ملاحظات

- مجلد `android/` يُولَّد أثناء البناء ولا يُرفع إلى المستودع.
- هذا غلاف Capacitor جديد حول ملفات الويب، وليس نسخة أندرويد الأصلية؛ اختبر التطبيق على جهاز قبل الاعتماد عليه.
- ملف Debug موقّع بمفتاح تجريبي، فقد لا يُثبَّت كتحديث فوق نسخة منشورة موقّعة بمفتاح آخر.
- الصلاحيات المضافة تلقائيًا: الكاميرا (مسح QR)، البصمة، الإشعارات.
